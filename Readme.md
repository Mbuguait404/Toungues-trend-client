# Tongues Trend - Client Application

Welcome to the frontend application for **Tongues Trend** — a premium 1-on-1 language tutoring platform connecting students with certified teachers worldwide.

## Tech Stack

This project is built with modern web technologies:
- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **UI Components**: [shadcn/ui](https://ui.shadcn.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: TypeScript

## Getting Started

First, make sure you have the required dependencies installed:

```bash
npm install
# or
pnpm install
```

Then, run the development server:

```bash
npm run dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Brand Colors

The platform uses a custom theme configuration:
- **Primary (Blue)**: `#1F509A`
- **Secondary (Orange)**: `#FBB23D`
- **Accent (Green)**: `#10B981`

## Project Structure

- `/app`: Next.js App Router pages and global layouts
- `/components`: Reusable React components (UI elements, Layout pieces)
- `/public`: Static assets like images and logos
- `/lib`: Utility functions and shared helpers
